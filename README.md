# PROG6212 - RaceDay

## Project Location

The API project is inside the RACEDAY.2 folder.

To run the API:
1. Open RACEDAY.2/RACEDAY.2.sln in Visual Studio.
2. Set RACEDAY.2 as the Startup Project.
3. Press F5 to launch Swagger at https://localhost:7234/swagger.

## Part 1

Part 1 deliverables are in the docs folder.

## Roles

The system has two roles:

Organiser - Creates and manages race events, defines categories, views enrolments, and captures race results.

Participant - Registers and logs in, manages their profile, views events and categories, enters events, and views their own results.

## API Setup Instructions

1. Clone the repository.
2. Open the solution file in Visual Studio.
3. Restore the NuGet packages.
4. Update the database using the command: Update-Database
5. Run the project with F5.
